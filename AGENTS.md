
- Les inscriptions en libre-service passent uniquement par la fonction `inscription` (Turnstile vérifié côté serveur, inscription directe coupée dans l’authentification) — empêche les robots de créer des comptes via l’API ; le secret TURNSTILE_DESACTIVE=true coupe la vérification sans republier.
- Les demandes de devis ne sont insérées que via `soumettre_demande_devis` ; un trigger BEFORE INSERT calcule `moderation`, et les emails prestataire/admin partent depuis la base (trigger + rattrapage dans la tâche nocturne des scores) avec réservation atomique de la date d'envoi — évite les envois non modérés, les doublons et les pertes d'email.
- Tout ce que voit ou compte un prestataire (accès, tableaux de bord, taux de réponse, score, compteurs) se limite aux demandes `moderation = 'valide'` — une demande suspecte ne doit jamais l'atteindre ni le pénaliser.
- La date d'une demande s'affiche partout via `formaterDateEvenement` (src/lib/dateDemande.ts, copie identique dans supabase/functions/_shared/date-demande.ts, vérifiée par un test) avec `date_precision` jour/mois — un mois seul ne doit jamais apparaître comme une date précise.
- Prerender: `signature_visible` = md5(data hash + `prerender_snapshot_version()`); bump that SQL version on any global component change (footer, nav, layout, home). Reconcile requeues the core pages immediately but only refreshes fiche signatures, leaving fiches to the nightly age-based batches — keeps the 1 GB headless renderer from being flooded.
- Dans `ai-playground`, aucun paramètre `temperature` n'est envoyé au provider anthropic (le modèle le refuse) ; il reste envoyé à Mistral, et la ligne `ia_tests` d'un appel Anthropic garde `temperature` NULL — évite l'erreur « temperature is deprecated for this model » et n'enregistre pas une valeur qui n'a pas été appliquée.
- tags_ia : le vocabulaire envoyé à Claude = liste d'ambiances fixe + « Éco-responsable » + options des champs `champs_categories.usage_ia = true` (communs, mère, fille de la fiche) ; filtrage exact côté code et 12 étiquettes max — empêche les étiquettes pratiques (paiement, délais) ou hors catégorie.
